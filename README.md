# TraderOS

**MT5 매매 습관 관리 도구** — 정해 둔 시간·상황에는 거래를 잠그고, 잠금 중에 들어간 포지션은 바로 청산합니다.
거래내역·손익·통계를 웹에서 보고, 알림과 실시간 현황은 텔레그램으로 받습니다.

> Windows + MetaTrader 5 전용입니다. 한국 시간(KST) 기준으로 동작합니다.

## ⚠️ 먼저 읽어 주세요

- 이 프로그램은 **실제 계좌의 포지션을 청산할 수 있습니다.** 처음에는 데모 계좌로 충분히 써 보고 실계좌에 쓰세요.
- 투자 판단과 그 결과(손실 포함)는 전적으로 사용자 책임입니다. 이 프로그램은 어떤 수익도 보장하지 않으며,
  버그·네트워크 문제·브로커 문제 등으로 생긴 손실에 대해 만든 사람은 책임지지 않습니다. (MIT 라이선스)
- 계좌 비밀번호는 이 PC 안(`data\`)에 암호화해서만 저장하며, 어디로도 보내지 않습니다.

## 할 수 있는 것

| 기능 | 설명 |
|---|---|
| 거래 잠금 | 정기 재확인(예: 새벽 30분마다), 연속 손절, 집중 구간(아시아장 등), 지표 발표일, 수동 잠금 |
| 일일 손실 한도 | 거래일(06:00) 시작 평가금 대비 손실률로 경고 → 새 진입 차단 → 전부 청산 (단계·비율은 설정, 기본 꺼짐) |
| 강제 청산 | 잠금 중에 들어간 포지션은 MT5 EA가 바로 청산하고 텔레그램으로 알림 |
| 잠금 풀기 | 정해 둔 확인 문구를 **직접 입력**해야 풀림 (웹·MT5·텔레그램) — 수동 잠금은 시간이 지나야만 풀림 |
| 웹 화면 | 포지션(SL/TP 일괄 설정), 거래내역(태그·메모·사진), 월간·연간 손익, 매매 통계 |
| 텔레그램 | 체결·잠금·강제청산 알림, 실시간 현황 메시지(계속 갱신), 잠금 풀기 |
| 여러 계좌 | 계좌마다 MT5를 따로 띄워 관리. MT5를 띄우지 않는 **조회 전용** 계좌도 가능 |
| 바깥 접속 | 내 PC에서 돌리면 Tailscale, 서버(VPS)에서 돌리면 도메인 + 비밀번호 로그인 |

## 준비물

- Windows 10/11
- [MetaTrader 5](https://www.metatrader5.com/) (브로커가 주는 MT5도 됨) — 설치만 해 두면 됩니다
- 거래할 MT5 계좌 (번호·비밀번호·서버 이름)
- (선택) 텔레그램 — 알림을 받으려면
- (선택) [Tailscale](https://tailscale.com/) — 밖에서 폰으로 보려면

Python은 설치 파일이 없으면 자동으로 설치합니다.

## 설치

1. [Releases](../../releases) 에서 최신 `TraderOS-vX.Y.Z.zip` 을 받아 원하는 곳에 압축을 풉니다. (예: `C:\TraderOS`)
2. 폴더 안의 **`start.bat`** 을 더블클릭합니다.
   - 처음에는 Python과 필요한 패키지를 설치합니다 (5~10분).
   - Windows 방화벽 창이 뜨면 **허용**을 누르세요. (폰에서 접속하려면 필요)
3. 서버가 켜지면 **관리 화면**(`http://127.0.0.1:8100/`)이 브라우저로 자동으로 열립니다.

서버는 `start.bat` 창이 열려 있는 동안만 동작합니다. 창을 닫으면 꺼집니다.

## 처음 설정

관리 화면에서 순서대로 하면 됩니다.

1. **계좌** 탭 → 계좌번호·비밀번호·서버 이름(MT5 로그인 창에 나오는 그대로)을 넣고 추가
   - 서버가 그 계좌용 MT5를 `C:\mt5\<계좌번호>\` 에 복사해서 띄웁니다. (처음엔 1~2분)
   - **처음 쓰는 브로커 서버라면** 뜬 MT5 창에서 *파일 → 거래 계좌 로그인* 으로 한 번 로그인하세요.
     "비밀번호 저장"에 체크하면 다음부터는 자동입니다.
   - **첫 계좌만 한 번:** MT5 창에서 *도구 → 옵션 → 전문가 조언자* → "다음 URL에 WebRequest 허용"에 체크하고
     `http://127.0.0.1:8000` 을 추가하세요. (EA가 서버와 통신하는 데 필요. 두 번째 계좌부터는 서버가 이 설정을 복사해 줍니다)
   - 차트에 `tradeLock` EA가 자동으로 붙습니다. 계좌 카드에 **EA 연결됨** 이 보이면 준비 끝.
2. **잠금 규칙** 탭 — 정기 재확인 시간대, 연속 손절 횟수, 집중 구간 등을 원하는 대로
3. **확인 문구** 탭 — 잠금을 풀 때 입력할 문구 (기본 문구가 들어 있음)
4. **텔레그램** 탭 (선택)
   1. 텔레그램에서 [@BotFather](https://t.me/BotFather) 에게 `/newbot` → 봇 토큰을 받아 붙여 넣기
   2. 만든 봇에게 `/start` 를 보내면 chat id를 알려줍니다 → 붙여 넣고 저장
   3. "실시간 현황"을 켜면 대화방에 현황 메시지가 생기고 계속 갱신됩니다

웹 화면은 `http://127.0.0.1:8000/app/` 입니다. (관리 화면의 **앱** 탭에서도 열 수 있음)

## 밖에서 (폰으로) 보기

관리 화면 **접속** 탭에서 고릅니다. 처음 설치하면 **Tailscale 전용**으로 되어 있어,
같은 와이파이의 다른 기기라도 Tailscale 없이는 들어올 수 없습니다.

- **내 PC에서 돌릴 때 — Tailscale (추천)**
  PC와 폰에 Tailscale을 설치하고 같은 계정으로 로그인 → 폰 브라우저에서 `http://<PC의 Tailscale 주소>:8000/app/`
  (주소는 접속 탭에 표시됩니다. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다)
- **집 안에서만 — 같은 네트워크**
  같은 와이파이·공유기에 붙은 기기(폰, 노트북, VM을 띄운 Mac 등)는 Tailscale 없이 `http://<PC의 내부 IP>:8000/app/` 로 들어옵니다.
  로그인이 없으니 **믿을 수 있는 집 네트워크에서만** 쓰세요. (카페·회사 와이파이 금지)
- **서버(VPS)에서 돌릴 때 — 공개 서버**
  접속 탭에서 비밀번호를 정하고 "공개 서버"를 선택 → nginx·Caddy 같은 HTTPS 리버스 프록시를 앞에 두세요.
  설정 예시는 접속 탭에 있습니다. (HTTPS 없이 인터넷에 그대로 열지 마세요)

관리 화면(8100)은 기본으로 **이 PC에서만** 열립니다. 다른 기기(폰, 맥의 가상머신 바깥 등)에서 열려면
이 PC의 관리 화면 **접속** 탭 → **관리 화면 원격 접속**에서 관리자 비밀번호를 정하고 켜세요.
같은 공유기·Tailscale 에서 온 접속만, 비밀번호로 로그인해야 들어옵니다. (켜기·비밀번호 변경은 이 PC에서만)
주소는 웹 화면처럼 `http://<PC 주소>:8000/admin/` 으로 열면 됩니다. (`:8100/` 으로 직접 열어도 됨)

## 조회 전용 계좌

계좌 탭에서 **MT5 실행**을 끄면 그 계좌는 MT5를 띄우지 않습니다. 저장된 거래내역·손익·통계만 볼 수 있고,
잠금·실시간 포지션·새 거래 기록은 멈춥니다. 끝난 계좌를 보관하거나 PC 메모리를 아끼고 싶을 때 쓰세요.

## 종목

웹 화면의 종목 버튼(골드·나스닥·오일·비트)은 브로커마다 다른 이름을 묶어서 찾습니다.
(예: `XAUUSD`, `XAUUSD+`, `GOLD` → 골드 / `NAS100`, `US100.b`, `USTEC` → 나스닥)
다른 종목을 쓰려면 `data\settings.json` 에 `"symbols"` 를 넣으세요. 모양은 `services\symbols.py` 의 `DEFAULT_GROUPS` 와 같습니다.

## 업데이트

새 버전이 나오면 텔레그램으로 알려 주고, 관리 화면 **업데이트** 탭에 표시됩니다.
**[업데이트]** 버튼을 누르면 새 버전을 받아 서버를 잠깐 껐다가(1~2분) 다시 켭니다.
텔레그램 알림의 **⬆️ 업데이트** 버튼이나 봇 명령 `/update` 로도 할 수 있고, 다 끝나면 완료 메시지가 옵니다.
설정·DB·사진(`data\`, `uploads\`)과 `.env` 는 그대로 남고, DB 구조가 바뀐 버전이면 켜질 때 자동으로 맞춥니다.
업데이트하는 동안 잠금 감시가 멈추니 거래 중이 아닐 때 하세요.

> 자동 업데이트는 `start.bat` 으로 켠 서버에서만 동작합니다 (서버가 꺼진 뒤 `start.bat` 이 파일을 바꾸고 다시 켜기 때문).
> 예전 버전(v0.1.1 이하)에서는 한 번만 아래처럼 직접 업데이트하면, 그 다음부터 자동입니다.

직접 업데이트하려면:
1. `start.bat` 창을 닫아 서버를 끕니다.
2. 새 zip을 **같은 폴더에 덮어쓰기**로 풉니다. `data\`, `uploads\` 는 zip에 없으므로 그대로 남습니다.
3. `install.bat` 을 한 번 실행한 뒤(패키지 갱신) `start.bat`.

## 백업 · 지우기

- 백업: `data\` 와 `uploads\` 폴더를 복사해 두면 됩니다. **`data\secret.key` 를 잃어버리면 저장된 계좌 비밀번호를 풀 수 없습니다.**
- 지우기: TraderOS 폴더와 `C:\mt5\` 를 지우면 됩니다.
- 로그(`logs\`)는 파일마다 5MB까지만 쓰고(넘으면 `.prev.log` 로 넘김), 30일 지난 로그는 자동으로 지웁니다.

## 설정 파일 (선택)

대부분은 관리 화면에서 바꿉니다. 폴더 위치 등은 `.env.example` 을 `.env` 로 복사해서 바꿀 수 있습니다.

## 폴더 구조

```
main.py               메인 서버 (:8000) - API, 웹 화면, 계좌별 MT5·워커 관리
trade_lock_worker.py  계좌별 워커 (:9000+계좌id) - MT5 연결, 연속 손절 감시
admin_ui/             관리 화면 (:8100, 이 PC에서만)
web_ui/               웹 화면 (/app/)
api/                  API
services/             잠금 규칙, 텔레그램, 접속 제한, EA 설치 등
mt5_ea/               MT5 EA (tradeLock)
db/                   DB 모델 (기본 SQLite: data\traderos.db)
```
