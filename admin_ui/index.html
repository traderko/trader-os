등록된 계좌

잠금을 켠 계좌는 서버가 MT5를 띄우고 거래 잠금을 감시합니다. 잠금을 꺼도 MT5 창은 닫지 않습니다.

불러오는 중…

계좌 추가

  1. 추가하면 서버가 이 계좌의 MT5를 띄웁니다 (MT5 실행을 끄고 추가하면 조회 전용이라 띄우지 않음). 처음에는 MT5를 복사하느라 1~2분 걸릴 수 있습니다.
  2. 이 PC에서 처음 쓰는 브로커 서버라면 MT5가 서버를 몰라서 자동 로그인이 안 됩니다. MT5 창에서 파일 → 거래 계좌 로그인을 열고, 서버 칸에 브로커 이름(예: Infinox)을 입력해 서버를 찾은 뒤 계좌번호·비밀번호로 한 번 로그인하세요. "비밀번호 저장"에 체크하면 다음부터는 자동입니다. 같은 서버의 계좌를 더 추가할 때는 이 과정이 필요 없습니다.
  3. tradeLock EA는 서버가 자동으로 차트에 붙입니다. 차트 왼쪽 위에 [TradeLock] 서버 통신 실패가 보이면 MT5의 도구 → 옵션 → 전문가 조언자에서 "WebRequest 허용"에 체크하고 http://127.0.0.1:8000을 추가하세요.
  4. 대시보드에서 "워커 실행 중"과 잔고가 보이면 연결된 것입니다.

시간이 지날 때마다 확인 문구를 다시 입력해야 거래할 수 있습니다. 시간대별로 간격을 다르게 정할 수 있고, 규칙끼리 시간대가 겹치면 안 됩니다. 시간은 한국 시간 기준입니다.

텔레그램 알림

잠금·해제·지표·체결 알림과 실시간 현황(대화방 맨 위에 고정되는 포지션·손익·잠금 상태)을 텔레그램으로 받습니다.

  1. 텔레그램에서 @BotFather에게 /newbot을 보내 봇을 만들고, 받은 토큰을 아래에 붙여넣고 저장합니다.
  2. 방금 만든 봇과의 대화방에서 /start를 보냅니다. 봇이 chat id를 답장해 줍니다.
  3. 아래 chat id 찾기를 누르거나 답장받은 숫자를 chat id 칸에 넣고 저장합니다.
  4. 테스트 전송으로 확인합니다. 잠시 뒤 대화방 맨 위에 실시간 현황이 고정됩니다.

봇이 답장하지 않으면 예전 방식으로 찾으세요: 토큰을 저장하고 봇에게 아무 메시지나 보낸 뒤 getUpdates 열기 ↗를 누르고, 나온 글에서 "chat":{"id":숫자 의 숫자를 chat id 칸에 넣습니다. (주소: https://api.telegram.org/bot토큰/getUpdates)

초마다

폰·다른 PC에서 접속

웹 화면(/app/)과 API를 바깥에서 어떻게 열지 정합니다. 이 PC 안의 MT5 EA·관리 화면은 어느 방식이든 그대로 동작합니다.

Tailscale 설정

  1. 이 PC와 폰에 Tailscale 앱을 설치하고 같은 계정으로 로그인합니다. (tailscale.com/download)
  2. 서버를 바깥 접속을 받도록 실행합니다: uvicorn main:app --host 0.0.0.0 --port 8000
  3. Windows 방화벽이 물어보면 허용을 누릅니다.
  4. 폰 브라우저에서 http://(Tailscale 주소):8000/app/ 을 엽니다. 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

공개 서버 설정

일
  1. 도메인을 서버 IP에 연결합니다 (DNS A 레코드).
  2. HTTPS 리버스 프록시를 둡니다. 가장 간단한 Caddy 예 (인증서 자동 발급): 
    내도메인.com {
    reverse_proxy 127.0.0.1:8000
}
    nginx를 쓰면 proxy_set_header X-Forwarded-For $remote_addr; 와 X-Forwarded-Proto $scheme; 를 꼭 넘기세요.
  3. 서버는 --host 127.0.0.1 로 띄워 프록시를 거쳐서만 들어오게 합니다.
  4. 폰에서 https://내도메인.com/app/ 을 열고 비밀번호로 로그인합니다.
