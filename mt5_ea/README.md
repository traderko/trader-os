# MT5 EA

- `tradeLock.mq5` / `tradeLock.ex5` : 거래 잠금 EA
  - 3초마다 서버(`http://127.0.0.1:8000/lock/status`)에 잠금 상태를 물어봄
  - 잠금 중에 들어간 포지션은 바로 청산 (매직넘버 990099)
  - 체결이 나면 서버(`/trades`)로 보내 거래내역을 기록 (실패하면 모아 뒀다가 다시 보냄)
  - 서버에 연결이 안 될 때는 **청산하지 않음** (서버를 재시작해도 포지션이 닫히지 않게)

서버가 계좌의 MT5를 띄울 때 이 EA를 그 MT5의 데이터 폴더(`MQL5\Experts`)에 복사하고,
시작 설정(config.ini `[StartUp]`)으로 차트에 자동으로 붙입니다. (`services/ea_installer.py`)

`.mq5`를 고치면 다음에 MT5를 띄울 때 MetaEditor 명령줄로 자동 컴파일합니다.

MT5에서 **도구 → 옵션 → 전문가 조언자 → "다음 URL에 WebRequest 허용"** 에 `http://127.0.0.1:8000` 이 있어야 합니다.
첫 계좌는 직접 추가해야 하고, 두 번째 계좌부터는 서버가 다른 MT5의 설정을 복사해 줍니다.
관리 화면에 "EA 연결 안 됨"이 보이면 이 설정부터 확인하세요.

- `sessionReporter.mq5` / `.ex5` : 거래 시간 알림 EA (**주문 · 청산 기능 없음 - 읽기만 함**)
  - 10분마다 보유 종목 · 시장 감시 창 종목의 앞으로 3일 거래 시간을 서버(`/market/sessions`)로 보냄
  - 브로커가 휴일에 바꿔 둔 거래 시간을 서버가 읽어서, 평소와 다른 종료(조기 종료 · 휴장)를 텔레그램으로 미리 알림
    (보유 중이면 60분 전 · 15분 전에도) - `services/market_watch.py`
  - 자동으로 붙지 않음: 계좌마다 MT5에서 **차트를 하나 새로 열고(파일 → 새 차트) 거기에 끌어다 놓기**
    - MT5는 차트 하나에 EA 하나만 붙음 - **TradeLock EA가 붙은 차트에 놓으면 TradeLock이 빠지니 절대 그 차트에는 놓지 말 것**
    - 주문을 안 하니 "알고리즘 거래 허용"은 필요 없음. WebRequest 허용 URL은 TradeLock과 같은 주소라 따로 넣을 것 없음
    - 한 번 붙이면 MT5 프로필에 저장돼서 서버 · MT5를 다시 켜도 남음 (서버의 차트 정리는 TradeLock 차트만 지움)
  - 안 붙여도 시세 멈춤 · 재개 알림과 미국 휴일 알림은 동작 (정확한 종료 시각만 빠짐)
