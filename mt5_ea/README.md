# MT5 EA

- `tradeLock.mq5` / `tradeLock.ex5` : 거래 잠금 EA
  - 3초마다 서버(`http://127.0.0.1:8000/lock/status`)에 잠금 상태를 물어봄
  - 잠금 중에 들어간 포지션은 바로 청산 (매직넘버 990099)
  - 체결이 나면 서버(`/trades`)로 보내 거래내역을 기록 (실패하면 모아 뒀다가 다시 보냄)
  - 서버에 연결이 안 될 때는 **청산하지 않음** (서버를 재시작해도 포지션이 닫히지 않게)

서버가 계좌의 MT5를 띄울 때 이 EA를 그 MT5의 데이터 폴더(`MQL5\Experts`)에 복사하고,
시작 설정(config.ini `[StartUp]`)으로 차트에 자동으로 붙입니다. (`services/ea_installer.py`)

`.mq5`를 고치면 다음에 MT5를 띄울 때 MetaEditor 명령줄로 자동 컴파일합니다.

MT5에서 **도구 → 옵션 → 전문가 조언자 → "다음 URL에 WebRequest 허용"** 에 `http://127.0.0.1:8000` 이 있어야 합니다.
첫 계좌는 직접 추가해야 하고, 두 번째 계좌부터는 서버가 다른 MT5의 설정을 복사해 줍니다.
관리 화면에 "EA 연결 안 됨"이 보이면 이 설정부터 확인하세요.
