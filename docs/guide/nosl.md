# 손절 없는 포지션 자동청산

손절(SL)을 안 걸고 버티다가 계좌가 반토막 나는 일을 막는 장치입니다. **기본은 꺼져 있습니다.**
[일일 손실 한도](loss-limit.md) 가 계좌 전체 기준이라면, 이건 **SL 없이 들고 있는 한 종목**만 봅니다.

## 어떻게 동작하나

1. 한 종목의 **SL 없는 포지션들** 손실(평가손익 + 스왑)이 잔고의 **10%**(설정)를 넘으면
2. 🔴 긴급 알림이 옵니다 — **60초 뒤 청산**
3. 60초 안에 아무것도 안 누르면 **그 종목의 SL 없는 포지션만** 시장가로 청산합니다

```
🔴🔴🔴 긴급 🔴🔴🔴
🧯 손절 없는 포지션 손실 12.0% · 60초 뒤 청산
━━━━━━━━━━━━━━
계좌 12345678 · NAS100+ BUY 2lot (SL 없음 2개) · 평가손익 -120.00
60초 안에 아무것도 안 누르면 이 종목의 SL 없는 포지션을 시장가로 청산합니다.
[✋ 이번엔 버티기] [🗡 지금 청산]
```

| 누르면 | 어떻게 |
|---|---|
| (아무것도 안 누름) | 60초 뒤 청산 |
| ✋ 이번엔 버티기 | 이번엔 두고, 손실이 **+10%p 더 커지면**(예: 22%) 다시 물어봄 |
| 🗡 지금 청산 | 2초 안에 바로 청산 |

- 카운트다운 중에 **SL 을 걸면** 그 포지션은 빠집니다 (다 걸면 "✅ 자동청산 취소")
- 손실이 기준보다 2%p 넘게 줄어도 취소됩니다
- **SL 이 걸린 포지션 · 다른 종목은 건드리지 않습니다**
- 거래내역의 청산 이유는 `🧯 손절 없음 자동청산`

## 켜고 끄기 — `/손절없음` (`/nosl`)

| 명령 | 하는 일 |
|---|---|
| `/손절없음` | 지금 설정 |
| `/손절없음 켜기` · `끄기` | 켜고 끄기 |
| `/손절없음 10` | 기준 % 바꾸기 (켜기도 같이) |
| `/손절없음 대기 60` | 카운트다운 초 (10~600) |

## 왜 10% 인가

손실이 커질수록 되찾기가 훨씬 어려워집니다: −10% 는 +11%, −30% 는 +43%, **−50% 는 +100%** 를 벌어야 원금입니다.
손절을 제대로 걸면 이 장치는 평소에 **한 번도 안 걸립니다.** 걸린다는 건 손절 없이 버티고 있다는 뜻입니다.

## 주의

- 계좌별 워커가 2초마다 확인합니다. 서버나 MT5 가 꺼져 있으면 동작하지 않습니다.
- 급하게 움직이는 장에서는 카운트다운 동안 손실이 더 커질 수 있습니다. 가장 좋은 건 들어갈 때 SL 을 거는 것입니다 (지침 '손절 미설정' 경고와 함께 쓰세요).
