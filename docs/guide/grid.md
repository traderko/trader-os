# 구간매매 (KTR 분할 진입)

정한 방향으로 **첫 진입은 시장가, 나머지는 KTR 간격마다 리밋 주문**으로 나눠 들어갑니다. 모든 주문에 같은 손절이 걸립니다.
"물타기를 하더라도 미리 정한 간격 · 크기 · 손절 안에서만" 하게 만드는 기능입니다.

웹 화면 **🧱 구간** 탭, 텔레그램 `/grid`, 실시간 현황의 **🧱 구간매매** 버튼에서 할 수 있고, 주문 전에 항상 **미리보기**(구간별 가격 · 랏 · 손절 손실 · 증거금)를 보여 줍니다.
거래가 잠겨 있으면 주문하지 않습니다.

## 두 가지 방식

| 방식 | 랏 | 손절 |
|---|---|---|
| **KTR 거래** | 손실 %(잔고 대비)를 먼저 정하면 구간마다 랏을 계산 — 동일손실(진입마다 손절 손실이 같게) / 차등손실(남은 예산의 절반씩) | 마지막 구간에서 0.5 · 1 · 1.5 KTR 더 간 곳 (기본 1) |
| **고정 랏 분할** | 구간마다 같은 랏 | KTR 배수 · 손실 %(손절선 자동) · 손절가 중에서 |

- **손절가로** — 주요 고점 · 저점을 손절가로 넣으면 그 안에 들어가는 구간 수를 자동으로 계산 (두 방식 다)
- **구간 수 자동** — 비우면 손절선과의 여유를 지키면서 증거금 안에서 가장 많이. 구간 수별 비교표에서 줄을 누르면 그 수로 바꿈

## 텔레그램

| 명령 | 하는 일 |
|---|---|
| `/grid` | 버튼으로 하나씩: 계좌 → 종목 → 방향 → 방식 → KTR 표 → 손실 % · 랏 → 손절 → 구간 수 → 미리보기 → 주문 |
| `/grid 나스닥 매수 5% 5구간` | 한 줄로 KTR 거래 미리보기 → [주문 실행] |
| `/grid 골드 매도 고정랏 0.1랏 손실5%` | 한 줄로 고정 랏 분할 (구간 수를 빼면 자동) |
| `/grid ?` | 한 줄 주문에 붙일 수 있는 말 전체 (`여유0.5` · `손절가20430` · `차등` · `아시아`/`유로`/`미장` · `2분`~`2시간` · `#계좌번호` …) |
| `/grids` | 진행 중인 구간매매 + [📋 상세] [대기 주문 취소] [전부 청산] |

## 묶음

구간매매 주문은 묶음(매직넘버)으로 관리되어 직접 거래와 구분됩니다 (포지션 탭 묶음, 거래내역 🧱KTR · 🧱고정랏 표시).
묶음 상세에서 구간마다 보유 · 대기 · 청산, 평단, 손절 시 손익, 다음 구간 도달 시 손익을 볼 수 있습니다.

## 첫 진입 추가 리밋

같은 종목 · 방향 포지션이 없을 때 들어간 **첫 진입**(나눠 들어간 것 합산)이 끝나면, 평균가에서 정한 KTR 마다 불리한 쪽으로 같은 랏 리밋을 N개 걸어 줍니다.
자동 또는 텔레그램 KTR 표에서 시간봉을 골라서. 첫 진입을 다 청산하면 자동으로 취소됩니다. 설정: 관리 화면 **텔레그램** 탭 → 구간매매.
거래 잠금 중에는 걸지 않습니다 (잠금 중에 건 리밋이 체결되면 EA 가 바로 청산하므로).
