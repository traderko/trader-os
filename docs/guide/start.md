# 처음 시작하기

설치(`start.bat`)를 마쳤다면 아래 5가지만 하면 기본 준비가 끝납니다. 자세한 설치 방법은 [README](../../README.md#설치) 에 있습니다.

## 1. 계좌 넣기 — 관리 화면 **계좌** 탭

계좌번호 · 비밀번호 · 서버 이름(MT5 로그인 창에 나오는 그대로)을 넣으면, 서버가 그 계좌 전용 MT5 를 띄우고 `tradeLock` EA 를 붙입니다.
계좌 카드에 **EA 연결됨** 이 보이면 성공입니다.

- 처음 쓰는 브로커 서버면 뜬 MT5 창에서 *파일 → 거래 계좌 로그인* 으로 한 번 로그인하세요 (비밀번호 저장 체크).
- 첫 계좌만 한 번: MT5 *도구 → 옵션 → 전문가 조언자* → "WebRequest 허용"에 `http://127.0.0.1:8000` 추가.

## 2. 텔레그램 연결 — 관리 화면 **텔레그램** 탭

1. 텔레그램에서 @BotFather 에게 `/newbot` → 봇 토큰을 받아 붙여 넣기
2. 만든 봇에게 `/start` 를 보내면 chat id 를 알려 줍니다 → 붙여 넣고 저장
3. **실시간 현황** 을 켜면 대화방 맨 위에 계속 바뀌는 현황 메시지가 생깁니다 → [실시간 현황](live.md)

이제 체결 · 청산 · 잠금 알림이 텔레그램으로 옵니다. 봇 메뉴(☰)에 쓸 수 있는 명령이 모두 나옵니다 → [명령 전체 목록](commands.md)

## 3. 잠금 규칙 정하기 — 관리 화면 **잠금 규칙** 탭

처음엔 기본값으로 써 보고, 내 매매 습관에 맞게 바꾸세요 → [거래 잠금](lock.md)

## 4. 지키는 장치 켜기 (추천)

| 장치 | 켜는 법 | 기본 |

## 5. 데모 계좌로 먼저

TraderOS 는 **실제 포지션을 청산할 수 있습니다.** 잠금이 어떻게 동작하는지 데모 계좌로 하루 이틀 써 보고 실계좌에 쓰세요.

## 업데이트

새 버전이 나오면 텔레그램으로 알려 줍니다. 알림의 **⬆️ 업데이트** 버튼이나 `/update` 로 업데이트하면 1~2분 뒤 다시 켜지고 완료 메시지가 옵니다.
설정 · 거래 기록은 그대로 남습니다. 업데이트하는 동안 잠금 감시가 멈추니 거래 중이 아닐 때 하세요.
