# KTR · 장 시작 브리핑

## KTR

**장 시작 봉 하나의 크기(고가 − 저가)** 로 그날의 변동성을 재는 단위입니다. 아시아장은 직전 봉 + 첫 봉.
장 3개(아시아 · 유로 · 미장) × 시간봉 5개(2분 · 5분 · 10분 · 1시간 · 2시간) 로 구합니다.

손절 · 구간 간격 · 목표를 포인트가 아니라 KTR 로 정하면 **변동성이 큰 날엔 넓게, 작은 날엔 좁게** 자동으로 맞춰집니다.

| 장 | 한국 시간 시작 |
|---|---|
| 아시아 | 07:00 (서머타임) / 08:00 |
| 유로 | 런던 08:00 (16:00 / 17:00) |
| 미장 | 22:30 (서머타임) / 23:30 |

## 명령

| 명령 | 하는 일 |
|---|---|
| `/ktr` | 오늘 KTR 표 (장 × 시간봉) + 주요 지표 발표 봉 크기 |
| `/ktr 최근` | 최근 7거래일 KTR 목록 + 7일 · 20일 평균. 평소의 1.3배 넘는 날 🔥, 0.7배 안 되는 날 💤 |
| `/ktr 브리핑 끄기` · `켜기` | 장 시작 자동 브리핑 |
| `/grid` · `/grids` | KTR 간격 구간매매 주문 · 진행 중인 것 보기 → [구간매매](grid.md) |
| `/bars 90` | 과거 봉(2분~2시간)을 zip 파일로 받기 — 직접 분석하고 싶을 때 |

## 장 시작 자동 브리핑 (기본 켜짐)

장 시작 10분 뒤(10분봉이 끝나면) 나스닥 · 골드의 오늘 KTR(2분 · 5분 · 10분)과 평소(20일 평균) 대비 배수를 보냅니다.
1시간 · 2시간 KTR 은 그 봉이 끝나면 **같은 메시지를 고쳐서** 채웁니다 (메시지가 여러 개 오지 않게). 휴장이면 보내지 않습니다.

## 오늘 KTR 이 평소보다 크면

시작 봉이 크다는 건 그날 변동성이 크다는 신호입니다. 같은 랏이면 되돌림도 그만큼 커서 평소처럼 들어갔다가 못 버티기 쉽습니다.
**KTR 이 평소의 1.3배면 랏을 그만큼 줄이는 것**이 같은 위험을 유지하는 방법입니다.
