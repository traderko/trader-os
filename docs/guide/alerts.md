# 알림 중요도

알림이 많아지면 정말 중요한 알림(강제청산 · 증거금 · 손실 한도)이 묻히기 쉽습니다.
알림 종류마다 중요도를 정해 두면 **중요한 것만 크게, 덜 중요한 건 조용히** 옵니다.

## 4단계

| 단계 | 어떻게 오나 |
|---|---|
| 🔴 **긴급** | 맨 위 큰 머리말 + 줄. **[✅ 확인] 을 누를 때까지 3분마다 다시** 보냄 (최대 5번). 긴급 전용 대화방이 있으면 거기에도 |
| 🟠 **중요** | 맨 위에 `🟠 중요 ·` 머리말 |
| ⚪ **보통** | 그대로 |
| 🔕 **조용** | **알림음 없이** 옴 (대화방에는 그대로 남음) |

```
🔴🔴🔴 긴급 🔴🔴🔴
🔒 증거금 사용률 잠금 - 추가 진입 차단
━━━━━━━━━━━━━━
계좌 12345678: 증거금 사용률 25% (한도 20%)
…
[✅ 확인 (다시 알림 멈춤)]
```

확인을 안 누르면 `🔁 다시 알림 1/5 · 확인 버튼을 눌러 주세요` 로 다시 옵니다. 2시간이 지나거나 최대 횟수가 되면 멈춥니다.

## 기본 중요도

| 단계 | 알림 |
|---|---|
| 🔴 **긴급** | 잠금 중 진입 강제청산 · 증거금 부족 강제청산(스탑아웃) · 손실 한도 차단 · 전부 청산 · 증거금 잠금 · MT5 응답 없음 · 손절 없는 포지션 청산 카운트다운(확인 버튼 · 다시 알림 없이 자체 버튼) |
| 🟠 **중요** | 증거금 경고 · 일일 손실 경고 · 돌파캔들(BOB) · 연속 손절 잠금 · 손실 직후 재진입 · EA 예전 버전 · 휴장 · 큰 수익 출금 · 지침(손절 미설정 · 지표 전 포지션 · 손절 직후 재진입) |
| ⚪ **보통** | 체결 알림 · 정기 재확인 · 잠금 풀림 · 출금 · 지갑 입금 · 원웨이 · 지표 예정 · 구간매매 · 나머지 지침 |
| 🔕 **조용** | 장 시작 KTR 브리핑 |

## 바꾸는 법

- **텔레그램 `/중요도`** (`/alerts`) — 알림마다 버튼. 누를 때마다 🔴 → 🟠 → ⚪ → 🔕 순서로 바뀝니다. [🔔 긴급 알림 시험] 으로 모양 확인
- **관리 화면 텔레그램 탭 → 알림 중요도** — 표로 한눈에, [전부 기본값] · [🔴 긴급 시험 보내기]
- 다시 알림 간격 · 횟수: `/중요도 반복 3 5` (3분마다 최대 5번, 0번이면 다시 안 보냄)

## 긴급 전용 대화방 (추천)

긴급 알림만 **다른 알림음**으로 받고 싶을 때:

1. 텔레그램에서 그룹을 만들고 (예: "TraderOS 긴급") 이 봇을 초대
2. 그 그룹에서 `/id` → 봇이 그 그룹의 chat id 를 알려 줌 (보통 `-100…`)
3. 봇 대화방에서 `/중요도 긴급방 -100…` (또는 관리 화면에 입력)
4. 폰에서 그 그룹의 알림 설정 → 알림음을 크게 · 다른 소리로

이제 🔴 긴급은 메인 대화방과 긴급 그룹 두 곳에 오고, 어느 쪽에서 [✅ 확인] 을 눌러도 다시 알림이 멈춥니다. 끄기: `/중요도 긴급방 끄기`

## 주의

- 긴급을 너무 많이 정하면 다시 알림이 계속 와서 오히려 무뎌집니다. **정말 바로 봐야 하는 것만** 긴급으로 두세요.
- 명령에 대한 답장(예: `/증거금`)은 중요도와 상관없이 그대로 옵니다. 중요도는 알림에만 적용됩니다.
