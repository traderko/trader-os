# 거래 분석 탭 (웹 🔬)

내 거래 기록과 그때의 1분봉을 맞춰서 **"들어간 뒤 얼마나 반대로 갔다가(역행), 얼마나 내 쪽으로 갔는지(순행)"** 와
**"증거금을 몇 % 썼을 때 계좌가 무너졌는지"** 를 보여 줍니다. 웹 화면 **🔬 분석** 탭에서 기간 · KTR 시간봉을 고르면 됩니다.

## 볼 수 있는 것

- **역행 · 순행 (MAE · MFE)** — 거래마다 진입 뒤 최대 역행 · 최대 순행을 포인트와 **KTR 몇 개**로. "보통 몇 KTR 역행을 버텨야 하나" 를 알 수 있음
- **증거금 사용률별 결과** — 포지션을 들고 있던 구간마다 최대 사용률을 구해서 0~5 · 5~10 · 10~20 · 20~30 · 30~50 · 50% 이상으로 나눠, 각 구간에서 계좌가 얼마나 빠졌는지 · 강제청산이 몇 번 있었는지
- **강제청산 찾기** — MT5 기록에서 증거금 부족 강제청산(💥)을 찾아 표시

## 처음엔 느릴 수 있어요

처음 보는 기간은 1분봉을 MT5 에서 받느라 몇 분 걸릴 수 있습니다. 화면이 진행 상황을 보여 주고, 받은 봉은 저장해서 다음부터는 빠릅니다.
결과 아래 '계산 시간' 에 단계마다 걸린 시간이 나옵니다. MT5 가 꺼져 있어서 실패하면 [다시 계산] 을 누르세요.
