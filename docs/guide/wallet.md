# 출금 지갑 잔고 (바이낸스 · 개인 지갑)

브로커에서 출금한 돈이 간 곳의 잔고를 텔레그램에서 한눈에 봅니다. **돈을 옮기는 기능은 없고 보기만 합니다.**

## 넣을 수 있는 것

| 종류 | 필요한 것 | 보이는 것 |
|---|---|---|
| 바이낸스 | 읽기 전용 API 키 (관리 화면 **지갑** 탭) | 현물(Spot) + 펀딩(Funding) 잔고, 최근 입금 |
| 개인 지갑 | **주소만** (개인키 필요 없음) | 기본 코인 + USDT · USDC 잔고 |

개인 지갑 네트워크: BSC · Ethereum · TRON · Polygon · Arbitrum · Base · Optimism · Avalanche · Solana · Bitcoin.
코인은 바이낸스 공개 시세로 USDT 로, USDT 는 업비트 공개 시세로 원화로 환산해 보여 줍니다.

## 명령

| 명령 | 하는 일 |
|---|---|
| `/잔고` (`/wallet`) | 바이낸스 · 개인 지갑 잔고 (USDT · 원화 환산) |
| `/잔고 추가 bsc 0x… 이름` | 개인 지갑 추가 (네트워크 · 주소 · 이름) |

5분마다 확인해서 **바이낸스 새 입금(완료)** 이나 **개인 지갑 잔고가 늘면** 텔레그램으로 알려 줍니다.

## 주의

- 바이낸스 API 키는 **'읽기' 만 켜고** 출금 · 거래 권한은 끄세요. IP 제한을 거는 것을 권합니다.
- 키는 이 PC 안에 암호화해서 저장하며 어디로도 보내지 않습니다.
- 주소만으로는 누구도 돈을 옮길 수 없습니다. 개인키 · 시드 문구는 **절대** 넣지 마세요 (넣을 칸도 없습니다).
