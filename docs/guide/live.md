# 실시간 현황

텔레그램 대화방 맨 위에 고정된 메시지 하나가 몇 초마다 고쳐집니다 (고칠 때는 알림이 울리지 않음). 폰 알림창 대신 이걸 보면 지금 상태가 한눈에 보입니다.
켜기: 관리 화면 **텔레그램** 탭 → 실시간 현황.

## 읽는 법

```
TraderOS 실시간 · 20:31
12345678  거래 가능 · 52분 뒤 재확인              ← 잠금 상태 (항상 보임)
평가금 10,385.60 · 손익 +385.00 (잔고 +3.8% · 증거금 +30%)
증거금 12.9%  ▰▱▱▱▱▱▱▱▱▱  여유 · 강제청산 200%
출금 가능 192.50 · 오늘 순수익 +385.00의 50%

강제청산까지
   XAUUSD+ BUY 0.4lot · ▼96pt(2.2%) → 4,370.27

XAUUSD+  +383.80 (+3.8%)
   BUY 0.4lot @ 4,466.27 (+9.60pt)
   SL 4,456.00 (평단 -10.27pt · 지금 -19.87pt) → -410.80 (-4.1%)
   TP 4,490.00 (평단 +23.73pt · 지금 +14.13pt) → +949.20 (+9.5%) (1/3)

전체 SL·TP시                                        ← 종목 · 방향이 2개 이상일 때
   SL 모두 닿으면 -750.00 (-7.5%) → 잔고 9,250.00
   TP 모두 닿으면 +1,010.00 (+10.1%) → 잔고 11,010.00
```

- 손익 옆 % 는 **잔고 대비**, SL · TP 줄의 `(1/3)` 은 3개 중 1개에만 걸렸다는 뜻
- **전체 SL·TP시** — 모든 SL(TP)에 닿으면 계좌 전체 손익. SL 없는 포지션은 빠지고 ⚠️ 로 알려 줌 (그 포지션은 손실 한도가 없다는 뜻)

## 버튼

[🔄 새로고침] · 잠겼을 때 [🔓 계좌 잠금 풀기] · 종목 · 방향마다 [🛑 SL] [🎯 TP] (SL/TP 가 포지션마다 다르면 [📋 맞추기]) · [🧱 구간매매] · [⚙️ 표시]

## 보일 것 고르기 — `/표시` (`/show`)

원웨이 · 돌파캔들(BOB) · EA 경고 · 평가금 · 증거금 · 출금 가능 · 강제청산까지 · 포지션 · 구간매매 · SL·TP 예상 손익 · SL·TP 버튼을 하나씩 켜고 끕니다. 잠금 줄은 항상 보입니다.

## 관련 명령

| 명령 | 하는 일 |
|---|---|
| `/pos` | 포지션 SL/TP 설정 (가격을 답장으로, 0 이면 해제) |
| `/calc` | 금액 → 가격 (SL · TP 를 얼마 손익 자리에 걸지) |
| `/sim 매수 26400 26500 1 나스닥` | 이 가격에 진입 · 청산하면 손익이 얼마인지 청산 알림 모양으로 미리보기 |
| `/손익` (`/pnl`) | 오늘 · 주 · 월 손익 (`/손익 어제`) |
| `/통계` (`/stats`) | 승률 · PF · 종목 · 장별 통계 |

## MT5 가 꺼졌을 때

MT5 가 2분 넘게 응답이 없으면 "⚠️ 계좌 ○○ MT5 응답 없음", 다시 붙으면 "✅ 다시 연결됨" 이 옵니다.
그 사이 보낸 명령은 "⚠️ MT5가 꺼져 있거나 다시 켜지는 중이에요" 로 답장이 오니 1~2분 뒤 다시 보내세요.
