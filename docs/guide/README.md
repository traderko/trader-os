# TraderOS 가이드

TraderOS 를 처음 쓰는 분을 위한 설명서입니다. 기능마다 **무엇인지 → 언제 쓰는지 → 켜고 끄는 법 → 실제 알림 예시 → 주의할 점** 순서로 적었습니다.
설치는 [저장소 첫 화면(README)](../../README.md) 을 먼저 보세요.

> 이 가이드는 프로그램과 같은 저장소에 있어서, 새 기능이 나오면 같은 업데이트에서 함께 고쳐집니다.
> 앱 안에서도 볼 수 있어요 — 웹 화면 오른쪽 위 **📖**, 텔레그램 `/도움말` (`/증거금 도움말` 처럼 명령 뒤에 붙여도 됨).

## 처음이라면 이 순서로

1. [처음 시작하기](start.md) — 설치 뒤 꼭 해야 할 설정 5가지
2. [거래 잠금](lock.md) — TraderOS 의 핵심. 잠기는 경우와 푸는 법
3. [실시간 현황](live.md) — 텔레그램 대화방 맨 위에서 계속 바뀌는 메시지 읽는 법
4. [증거금 경고 · 증거금 잠금](margin.md) — 비중을 너무 크게 실을 때 막아 주는 장치
5. [일일 손실 한도](loss-limit.md) — 하루에 잃을 수 있는 한도

## 용어

| 말 | 뜻 |
|---|---|
| **KTR** | 장(아시아 · 유로 · 미장)이 시작한 봉 하나의 크기(고가 − 저가). 그날 변동성의 단위로 씀. 아시아장은 직전 봉 + 첫 봉 |
| **증거금 사용률** | 사용 증거금 ÷ 평가금. 높을수록 조금만 반대로 가도 강제청산에 가까움 |
| **거래일** | 한국 시간 07:00(미국 서머타임) / 08:00 에 바뀜. 손익 · 출금 · 손실 한도는 이 기준 |
| **잠금** | 정해 둔 상황에서 새 진입을 막는 것. 잠긴 동안 들어간 포지션은 MT5 EA 가 바로 청산 |
