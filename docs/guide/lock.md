# 거래 잠금

TraderOS 의 핵심 기능입니다. **정해 둔 시간 · 상황에는 거래를 잠그고, 잠긴 동안 들어간 포지션은 MT5 EA 가 바로 청산**합니다.
"지금은 들어가면 안 되는 때"를 의지가 아니라 시스템으로 지키게 해 줍니다.

## 언제 잠기나

| 잠금 | 언제 | 푸는 법 |
|---|---|---|
| 정기 재확인 | 정해 둔 주기마다 (기본: 새벽 0~7시 30분마다, 그 외 2시간봉 마감마다) | 확인 문구 입력 |
| 연속 손절 | 최근 24시간 안에 3번 연속 손절 (횟수 · 기간 설정) | 확인 문구 입력 → 60분 동안 풀림 |
| 집중 구간 | 요일 · 시간을 정해 둔 구간 (기본: 목 · 금 아시아장 + 주요 지표 발표일) | 그 구간 전용 문구 |
| 수동 잠금 | 내가 직접 `/잠금 90` 처럼 시간을 정해 잠금 | **못 풂** — 시간이 지나야 풀림 |
| [일일 손실 한도](loss-limit.md) | 오늘 손실이 정한 % 를 넘음 | 못 풂 — 다음 거래일 시작에 풀림 |
| [증거금 잠금](margin.md#증거금-잠금) | 증거금 사용률이 한도를 넘음 | 사용률이 내려가면 저절로 |

주말(한국 토 06/07시 ~ 월 06/07시)에는 정기 재확인 · 집중 구간 잠금을 쉽니다. 수동 · 연속 손절 · 손실 한도 잠금은 주말에도 그대로입니다.

## 잠긴 동안 들어가면

잠긴 순간 이미 들고 있던 포지션은 그대로 둡니다. **잠긴 뒤에 새로 들어간 포지션만** EA 가 바로 청산하고 텔레그램으로 알려 줍니다.
잠기기 전에 걸어 둔 대기 주문(리밋 · 스탑)이 잠금 중에 체결된 것은 봐줍니다. 잠금 중에 새로 건 대기 주문이 체결되면 청산됩니다.

```
🔒 잠금 중 진입 → 강제청산
NAS100+ BUY 1lot · 손익 -3.20
잠금 사유: 정기 재확인
거래 잠금 상태에서 들어간 포지션이라 tradeLock EA가 바로 청산했습니다.
```

## 푸는 법 — 확인 문구

잠금을 풀려면 정해 둔 문구를 **띄어쓰기까지 똑같이 직접 쳐야** 합니다. 붙여넣기처럼 너무 빨리 오면 거절합니다.
"잠깐 멈추고 생각하게" 만드는 장치입니다.

- 웹 화면 [잠금 풀기] 버튼, MT5 EA 화면, 텔레그램 `/unlock` (또는 실시간 현황의 [🔓 잠금 풀기] 버튼) 어디서든
- 문구 보기 · 추가 · 고치기: 관리 화면 **확인 문구** 탭 또는 `/문구`
- 입력 그만두기: `/cancel`

## 수동 잠금 — `/잠금 90`

"오늘은 더 하면 안 되겠다" 싶을 때 스스로 잠급니다. 정한 시간(분) 동안은 **문구로도 풀 수 없습니다** (최대 24시간).

## 트레이딩 지침

잠그지는 않지만, 위험한 상황이 생긴 순간 맞는 지침 문구를 텔레그램으로 보냅니다.
복수매매(손절 직후 재진입), 과매매, 같은 가격 반복 진입, 평소보다 큰 비중, 손절 미설정, [증거금 경고](margin.md),
목 · 금 아시아장 역매매, 장 시작 · 지표 발표 전 포지션 정리 등. 규칙마다 관리 화면 **지침** 탭에서 켜고 끕니다.

- `/지침` — 지침 문구마다 중요도(★1~5). ★ 가 많을수록 '무작위 지침' 에 자주 나옴
- `/무작위` — 지침 하나 뽑아 보기
- `/지표` — 이번 주 지표 발표 · 지표일 잠금 구간 → [지표 발표일 잠금](events.md)

## 주의

- 잠금 감시는 서버가 켜져 있어야 동작합니다. 서버 · MT5 가 꺼지면 텔레그램으로 알려 줍니다.
- 잠금 규칙을 고친 뒤에는 관리 화면에서 **저장**해야 적용됩니다. 칸마다 **기본값** 버튼으로 처음 값으로 되돌릴 수 있습니다.
