# 근거 태그 · 근거별 성과

거래마다 **왜 들어갔고 왜 나왔는지** 태그를 달아 두면, 웹 **통계** 탭에서 근거마다 승률 · 손익비 · 기대값을 보여 줍니다.
"내가 잘 먹는 자리" 와 "늘 잃는 자리" 를 숫자로 확인하는 기능입니다.

## 다는 법

- **진입 · 청산 알림에서 바로** — 텔레그램 체결 알림 아래 [🏷 근거] 버튼으로 고르기 · 새로 만들기 · 메모
- **나중에 몰아서** — `/근거` (`/reasons`) 또는 `/근거 3일` → 근거 없는 최근 거래를 묶음별로 + [🏷 진입] [🏷 청산] 버튼
- **웹 거래내역** — [🏷 근거 없음] 필터 → ☑ 로 여러 건 골라 [🏷 근거 달기] · [📦 묶기] (나눠 들어간 거래를 한 묶음으로)

관리 화면 **텔레그램** 탭 → 근거 알림을 켜면 정해진 시각이나 주기마다 근거 없는 거래를 모아 보내 줍니다.

## 팁

진입 때마다 다는 게 번거로우면, 하루 한 번 `/근거 1일` 로 몰아서 다는 것만으로도 충분합니다. 태그는 적게(5~10개) 유지할수록 통계가 의미 있어집니다.
