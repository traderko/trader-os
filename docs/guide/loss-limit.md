# 일일 손실 한도

하루(거래일)에 잃을 수 있는 한도를 정해 두면, 넘었을 때 단계별로 막습니다. **기본은 꺼져 있습니다.**

## 단계

거래일 시작 평가금 대비 오늘 손실률로 판단합니다. 그날 입금 · 출금은 기준에서 빼고 셉니다.

| 단계 | 기본 | 하는 일 |
|---|---|---|
| 경고 | 5% | 텔레그램 경고 |
| 차단 | 7% | 새 진입 차단 — 다음 거래일 시작까지 **못 푸는 잠금** (지금 포지션은 그대로, 대기 주문 취소) |
| 청산 | 10% | 모든 포지션 청산 + 다음 거래일까지 잠금 |

차단 · 청산은 10초 동안 계속 넘어 있을 때만 실행합니다 (스프레드가 순간 튀어서 잘못 청산되지 않게). 0 으로 두면 그 단계는 쓰지 않습니다.

## 켜고 끄기

관리 화면 **잠금 규칙** 탭 → 일일 손실 한도. 실시간 현황 잠금 줄에 오늘 손실률이 함께 보입니다 (`· 오늘 −3.2%`).

## 예시

```
⛔ 일일 손실 한도 - 새 진입 차단
계좌 12345678: 오늘 손실 7.1%
11/28 07:00까지 새로 들어가는 포지션은 바로 청산됩니다. 지금 포지션은 그대로 둡니다. (문구로 풀 수 없음)
```

## 주의

- '청산' 단계는 손실 중인 포지션도 전부 닫습니다. 처음엔 경고 · 차단만 쓰고 익숙해지면 청산을 켜세요.
- 관리 화면에서 손실 한도로 걸린 잠금만 따로 풀 수 있습니다 (사람이 건 수동 잠금은 그대로).
