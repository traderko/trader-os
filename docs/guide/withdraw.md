# 출금 알림

**번 돈을 다시 매매에 넣기 전에 빼 두게** 도와주는 기능입니다. 브로커에 출금 API 가 없어서 출금은 직접 하고, 금액 계산과 알림만 자동입니다.

## 출금 규칙

오늘(거래일) 순수익의 **50%**(설정)까지 출금할 수 있다고 계산합니다. 이미 출금한 금액은 빼고, 다음 거래일이 되면 새로 셉니다.
웹 **손익** 탭의 출금 카드와 같은 계산입니다. % 는 손익 탭에서 바꿉니다.

## 알림 두 가지

**1) 장 바뀌기 전 알림 (기본 켜짐)** — 유로장 시작 · 미장 시작 · 거래일 끝나기 30분 전에 계좌마다 오늘 출금 가능액.
0 이거나 지난번과 같은 금액이면 보내지 않습니다. 알림 뒤 출금이 잡히면 "✅ 출금 확인됨 · 남은 출금 가능" 도 옵니다.

**2) 큰 수익 알림 (기본 켜짐)** — 오늘 청산해서 확정된 수익이 거래일 시작 잔고의 **20% · 40% · 60% …** 를 넘을 때마다 바로.

```
🎉 오늘 실현 수익 +322% (시작 잔고 450.00) · 출금 가능 · 12345678 (한텍)
725.00  (오늘 순수익 +1,450.00의 50%)
08:00 전에 출금해야 오늘 몫으로 계산됩니다 (그 뒤면 다음 거래일 몫에서 빠짐)
[📋 금액 복사] [💸 한텍 출금 페이지]
```

## 명령

| 명령 | 하는 일 |
|---|---|
| `/출금` (`/withdraw`) | 지금 계좌마다 출금 가능액 + 버튼 |
| `/출금 알림 30` · `끄기` · `켜기` | 장 바뀌기 몇 분 전에 알릴지 (10~300) |
| `/출금 큰수익 20` · `끄기` · `켜기` | 큰 수익 알림 단계 % |
| `/잔고` (`/wallet`) | 출금받는 바이낸스 · 개인 지갑 잔고 · 입금 알림 → [지갑 잔고](wallet.md) |

## 주의

- 거래일이 바뀐 뒤(한국 07시, 서머타임 아닐 때 08시)에 출금하면 **다음 거래일 몫**에서 빠집니다.
- 출금 페이지 버튼은 한텍 · 인피녹스만 압니다. 다른 브로커면 금액 복사 버튼만 나옵니다.
