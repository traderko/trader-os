# 텔레그램 명령 전체 목록

봇 메뉴(☰)에 나오는 명령과 같습니다. 한글 명령(`/증거금`, `/출금` 등)도 같은 기능입니다.

| 명령 | 하는 일 | 자세한 설명 |
|---|---|---|
| `/help` | 가이드 - 기능마다 쓰는 법 · 알림 예시 (/도움말 · /증거금 도움말) | [처음 시작하기](start.md) |
| `/alerts` | 알림 중요도 - 🔴 긴급 · 🟠 중요 · ⚪ 보통 · 🔕 조용 (/중요도) | [알림 중요도](alerts.md) |
| `/unlock` | 거래 잠금 풀기 (문구 직접 입력) | [거래 잠금](lock.md) |
| `/lock` | 스스로 잠그기 - 정한 시간 동안 문구로도 못 풂 (/잠금 90) | [거래 잠금](lock.md) |
| `/accounts` | 계좌 목록 · 기본 계좌(★) 바꾸기 (/계좌) | [웹 화면 둘러보기](web.md) |
| `/guide` | 지침 중요도(★1~5) 바꾸기 (/지침) | [거래 잠금](lock.md) |
| `/random` | 지침 하나 무작위로 보기 (/무작위) | [거래 잠금](lock.md) |
| `/server` | 서버 PC 사양 · 상태 (CPU · 램 · 저장공간 · IP) (/서버) | [처음 시작하기](start.md) |
| `/bob` | 돌파캔들(BOB) 알림 - 반대 포지션 경고 · 시간봉 켜기·끄기 | [돌파캔들(BOB) 알림 · 원웨이 알림](bob.md) |
| `/wallet` | 바이낸스 · 개인 지갑 잔고 (/잔고 · /잔고 추가 네트워크 주소 이름) | [출금 지갑 잔고 (바이낸스 · 개인 지갑)](wallet.md) |
| `/withdraw` | 출금 가능액 · 출금 알림 (/출금 알림 30 · /출금 큰수익 20) | [출금 알림](withdraw.md) |
| `/show` | 실시간 현황에 보일 것 켜고 끄기 (/표시) | [실시간 현황](live.md) |
| `/oneway` | 원웨이 장 - 지금 몇 KTR 갔는지·알림 설정 (/원웨이) | [돌파캔들(BOB) 알림 · 원웨이 알림](bob.md) |
| `/pnl` | 손익 - 오늘·주·월 (/손익 어제) | [실시간 현황](live.md) |
| `/stats` | 매매 통계 - 승률·PF·종목·장별 (/통계) | [실시간 현황](live.md) |
| `/pos` | 포지션 SL/TP 설정 | [실시간 현황](live.md) |
| `/calc` | SL·TP 예상 손익 계산 | [실시간 현황](live.md) |
| `/grid` | 구간매매 - 버튼으로 하나씩 설정 (또는 한 줄로) | [구간매매 (KTR 분할 진입)](grid.md) |
| `/grids` | 진행 중인 구간매매·청산 | [구간매매 (KTR 분할 진입)](grid.md) |
| `/ktr` | KTR 표 (장 × 시간봉) · /ktr 최근 (7거래일) · /ktr 브리핑 | [KTR · 장 시작 브리핑](ktr.md) |
| `/margin` | 증거금 사용률 알림 · 잠금 (/margin 알림 10 20 30 · /margin 잠금 20) | [증거금 경고 · 증거금 잠금](margin.md) |
| `/bars` | 과거 봉 파일로 받기 (/bars 90 · /bars 90 gold) | [KTR · 장 시작 브리핑](ktr.md) |
| `/reasons` | 근거 없는 거래 모아 보기 (/근거 3일) | [근거 태그 · 근거별 성과](reasons.md) |
| `/events` | 이번 주 지표 발표·지표일 잠금 (/지표) | [지표 발표일 잠금 · 이번 주 지표](events.md) |
| `/phrases` | 잠금 풀기 확인 문구 보기·추가·수정 (/문구) | [거래 잠금](lock.md) |
| `/sim` | 청산 시뮬레이션 (알림 미리보기) | [실시간 현황](live.md) |
| `/update` | 새 버전 확인·업데이트 | [처음 시작하기](start.md) |
| `/cancel` | 잠금 풀기 그만두기 | [거래 잠금](lock.md) |
| `/id` | 이 대화의 chat id 보기 | [처음 시작하기](start.md) |
